## 规则

1. 记录每项内容的实际来源，不再把 R0 clean-room 约束当作 main 重写的限制；方向见 ADR-0009。
2. main/SGBY 内容通过可重复导入工具进入 `content/main/`，不手工伪造导入结果；保留原始索引与 golden 对照。
3. Electron、联网代码、调试页和 WASM 不进入 Godot 生产运行时；规则按可观察行为用 C# 重写。
4. 商标、授权及其他合规事项按用户决定后置，后续重新纳入发行检查时以本表为线索。
