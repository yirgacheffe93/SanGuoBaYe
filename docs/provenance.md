## 规则

1. **代码**：不复制 iBaye / baye-alpha 的实现；可以参考高层行为描述，但重写实现。
2. **数据**：不从 `.lib` 提取数值表、地图坐标、人物数据；使用自己的设计/考据。
3. **文本**：不抄原版对白/说明；引用史书要注明来源，现代译注需确认授权。
4. **美术/音频**：原创、购买或使用明确授权的素材；保留授权文件/链接。
5. **字体**：确认商用授权；记录字体名称/版本/授权范围。
6. **名称/商标**：正式名称检索后再使用；不蹭原游戏名称。
7. **审查**：发行前请律师检查本表和相关文件。
