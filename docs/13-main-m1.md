# 13 · Main-M1 验收记录

> 状态：190 年刘备内政垂直切片已完成。它是 main 重写的第一个可玩阶段，不是完整战略层或战术战斗实现。方向见 ADR-0009。

## 1. 内容导入

`node tools/main-import/import.mjs --check` 使用 main 的真实 `libs/SGBY.lib` 重复导出并逐字节比对，33 项导入检查通过：

- 4 个时期：190、198、208、225 年 1 月。
- 每期 38 城、200 条人物记录；共 152 条城市、800 条人物记录。
- 33 道具、30 技能，以及每期 200 个原始命令槽位。
- 保留原始零基索引、`city-005`/`person-013` 等稳定 ID、原始一基引用和规范化 ID。
- 记录 main commit、库、引擎、bridge 与 WASM 哈希。生产 Godot 只读 JSON，不加载 WASM。

`content/main/content.schema.json` 和 `scenarios.schema.json` 负责结构校验，`MainContentLoader` 负责数量、引用、归属和数值语义校验。最高武力/智力 150 未被截断。

## 2. 已对齐的 main golden

190 年 1 月刘备、平原及城内顺序已验证：

- 平原归属刘备，城内为刘备、关羽、张飞、吴懿、丁奉。
- 农业 938/2470，商业 845/2486，民忠 68。
- 人口 32225/87096，金 93，粮 234，后备兵 0。
- 刘备武力 85、关羽 106、张飞 107。
- 双股剑、青龙刀、丈八矛的名称和定义已导入。

18 名 190 年可选君主由实际人物自归属和城市归属关系生成。

## 3. M1 可玩流程

用户可在 Godot 或独立 macOS 应用中完成：

1. 选择 190 年和刘备，进入 38 城地图。
2. 在平原查看 5 名武将及属性、体力和道具。
3. 选择关羽开垦，支付 50 金和 10 体力，进入 1 个月命令队列。
4. 取消并全额退款，或重新安排后点击策略结束。
5. 关羽完成开垦，平原农业从 938 变为 946，日期进入 190 年 2 月。
6. 其他势力在月末执行实际开垦命令，不保持静态背景。
7. 存档、读档并继续一个月，结果与连续执行一致。

## 4. 明确的实现边界

> M2A 已取得真实 golden 并修正本节的临时规则：现为 8 体力、接受时生效、seed=1 时农业 +64、月末归队，且不再承诺取消退款。以 `14-main-m2a.md` 为当前行为依据，本节仅保留 M1 当时记录。

- 50 金成本来自 main 命令接口。当前 M1 的 10 体力、1 个月和 `max(1, floor(IQ/10))` 农业增长是本切片实现规则；main 的开垦接受/取消/月末 golden 未能可靠捕获，未宣称这些字段已等价。
- 当前月末处理命令、农业和日期；完整月度收支、灾害、经验、忠诚及 main AI 等价属于 M2。
- main 未导出可靠地图矩阵或逐城坐标，当前使用明确标注的重写网格布局，不冒充 main 原图。
- 其他时期和君主已在内容层导入，UI 暂不开放；完整战略命令、出征和独立战术战斗不在 M1 范围。
