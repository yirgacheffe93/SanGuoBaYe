## 2. 月度规则

`MainMonthService` 按 main 顺序执行：

```text
六月/十月：先收获
每三月：再收入
全体武将体力 +4
城市季度防灾、金钱上限、人口和粮耗
随机事件
```

公式：

```text
Money < 30000 时：Money += floor(Commerce / 2)
Food < 30000 时：Food += floor(Farming / 4)
```

收入与收获覆盖所有城市，不在公式内强行钳到 30000。十二月到一月同时推进年份，全体人物年龄 +1；没有添加通用经验或忠诚奖励。

已验证：

| 月份 | 结果 |
|---|---|
| 三月 | 金 93→515、粮 228→222、人口 32275→32325、防灾 62→61 |
| 六月 | 金 515→937、粮 210→438、人口 32425→32475、防灾 61→58 |
| 十月 | 粮 420→648，无税收、无季度防灾衰减 |

六月明确验证先收获和税收再扣粮耗。月度报告现在包含收获、税收和年份变化。

## 4. 道具发现位已修复

根因已由 `20-setgoods-diagnosis-result.md` 确认：生产 WASM 正常写入 `0x8000`，旧诊断和导入器误把 U8 字节视图当成 U16 队列。真实读取应为 `base + queueIndex × 2` 的 U16LE。

已完成修复：

- 导入器按真实地址和 U16LE 重读，四时期 60 条受影响城市记录已纠正；许昌正确队列为 `[7,8,12]`。
- 成功搜寻按同源 C 标记本城第一个同 ID 且未发现的队列项，不增加 RNG、不删除道具、不改装备。
- 北平 `state=43` 的正式 golden 为 `31→32799`，最终 RNG 1008917062。
- 已验证防重复、重复项顺序、混排、两城隔离、伯乐不匹配、空候选、存读档和静态内容隔离。
- 重导改变 ContentHash，旧存档按既有机制拒绝，没有强行兼容。

旧 `queueDiscovered=false` 仅是误诊历史，不再作为完成态结论。
