# 三国霸业现代化改造项目规划

## 1. 项目目标

基于开源项目 [baye-alpha](https://github.com/kvinwang/baye-alpha)，将经典游戏《三国霸业》改造为适合现代桌面设备的独立游戏，未来计划上架 Steam。

**核心原则：保留原版游戏体验，只改造运行方式和 UI。**

- 保留三国历史背景、武将、剧情及核心玩法。
- 保留原有游戏规则、数值系统和战斗机制。
- 优化游戏画面、界面布局与交互体验。
- 优先支持 macOS，未来扩展 Windows、Steam Deck。
- 尽量复用原有代码，避免重写游戏引擎。

## 2. 技术方向

采用 **原游戏引擎 + 现代化 UI + Electron 桌面容器** 的方案。

| 模块 | 技术方向 | 说明 |
|---|---|---|
| 游戏引擎 | 复用 baye-alpha / iBaye | 保留核心游戏逻辑 |
| UI | HTML / CSS / JavaScript | 根据现有渲染方式逐步改造 |
| 桌面运行 | Electron | 优先支持 macOS |
| 应用打包 | electron-builder | 生成 macOS 应用 |
| 存档系统 | 本地持久化 | 兼顾未来 Steam Cloud |
| 输入系统 | 键盘、鼠标 | 预留手柄支持 |

尽量不引入大型前端框架，降低开发复杂度。

## 3. 第一阶段：macOS 桌面化

**目标：让原版游戏作为独立 Mac 应用稳定运行。**

主要任务：

1. Fork 原始 GitHub 仓库。
2. 梳理项目结构与游戏运行方式。
3. 集成 Electron，实现桌面启动。
4. 支持离线运行、窗口缩放和全屏。
5. 验证游戏存档与读取功能。
6. 打包 macOS 应用，优先适配 Apple Silicon。

验收标准：

- 双击应用即可启动游戏。
- 不依赖浏览器或外部服务器。
- 原有玩法和剧情正常运行。
- 存档、读档稳定可靠。

## 4. 第二阶段：UI 现代化

**目标：保留经典游戏风格，同时提升画面质感和操作体验。**

设计方向：

- 美术：现代像素风，结合三国古典元素。
- 配色：统一地图、面板、文字和按钮的视觉风格。
- 布局：适配现代宽屏显示器。
- 交互：改善信息展示、按钮反馈和操作便利性。
- 画面：优化素材清晰度与不同分辨率下的显示效果。

优先改造以下界面：

1. 游戏主菜单
2. 武将信息面板
3. 城池和内政界面
4. 战斗界面
5. 地图及各类操作菜单

原则上只修改视觉呈现和交互，不改变游戏规则。

对于 Canvas 或引擎内部绘制的界面，需要根据实际代码结构决定改造方式，避免为了更换 UI 而重写整个引擎。

## 5. 第三阶段：跨平台与 Steam

在 macOS 版本稳定后，逐步扩展。

| 平台 | 计划 | 实现方向 |
|---|---|---|
| macOS | 第一版 | Electron 原生桌面应用 |
| Windows | 第二版 | 复用游戏代码，增加 Windows 打包 |
| Steam Deck | 第三版 | 优先验证 Proton 兼容性，适配手柄 |
| Steam | 后续发行 | 集成 Steamworks，完成商店与发行流程 |

未来可考虑增加 Steam 成就、云存档、游戏设置等功能，但不纳入第一版范围。

## 6. 架构预留

为了降低后续跨平台改造成本，开发时遵守以下原则：

- **游戏逻辑与 UI 分离**：尽量避免视觉改造影响原有玩法。
- **平台能力独立封装**：文件、窗口和系统功能不直接写入游戏逻辑。
- **输入统一抽象**：为未来手柄操作预留扩展空间。
- **存档格式稳定**：避免因 UI 改造破坏游戏数据。
- **分辨率自适应**：兼容 Mac 桌面，预留 Steam Deck 小屏幕适配。
- **依赖尽量精简**：优先使用现有技术，减少维护成本。

上述原则按需实施，不在第一版进行不必要的大规模重构。

## 7. 暂不考虑的内容

- 修改三国历史背景或剧情。
- 增加新武将、新势力和新地图。
- 修改战斗机制与游戏数值。
- 开发多人联机。
- 重写游戏引擎。
- 开发移动端版本。
- 第一阶段接入复杂的 Steam 功能。

## 8. 项目风险

**技术风险**

原游戏部分界面可能由底层引擎直接绘制，UI 改造难度需要通过代码分析确认。

**版权风险**

正式公开发行或商业上架前，需要确认原游戏代码、引擎、素材、音乐等内容的授权范围。三国历史题材本身不等于原游戏具体作品可以自由商业使用。

**兼容性风险**

桌面化过程中，需要重点验证存档、资源加载、窗口缩放及游戏输入行为。

## 9. 开发里程碑

- [ ] M1：原项目本地运行成功
- [ ] M2：Electron macOS 版本运行成功
- [ ] M3：离线运行和存档功能验证完成
- [ ] M4：确定统一 UI 视觉风格
- [ ] M5：完成核心界面现代化改造
- [ ] M6：完成 macOS 版本测试与打包
- [ ] M7：确认发行授权与 Steam 上架可行性
- [ ] M8：启动 Windows 和 Steam Deck 适配

---

## 10. 总体方向

**第一版：经典三国霸业 + 现代化 UI + macOS 独立应用。**

优先完成一个稳定、完整、好看且保留原汁原味玩法的 Mac 版本。

后续在不改变核心架构的前提下，逐步支持 Windows、Steam Deck，最终实现 Steam 多平台发行。
