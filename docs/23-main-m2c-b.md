## 2. 军备公式

```text
征兵上限 = min(民忠×20, 金×10, 65534)
实际金耗 = floor(人数/10)
后备兵 = min(65535, 后备兵 + 人数)
```

征兵不扣人口，接受时生效，月末只归队，不重复加兵。

```text
分配上限 = Level×100 + Force×10 + IQ×10
新后备兵 = 原后备兵 + 原武将兵 - 新武将兵
```

掠夺月末：`粮食 += 5×(IQ+Force)`、`金钱 += 2×(IQ+Force)`，民忠/农业/商业减半，保留 U16 行为。

## 3. 招降与人物处置

招降只接受俘虏：

1. `gate=(执行者IQ-目标IQ+50)&0xff`，第一次随机超过则失败。
2. 忠诚先扣 10%，大于 60 直接失败。
3. 按性格系数进行第二次判定：卤莽2、怕死5、贪财4、大志3、忠义1。
4. 成功时改归属，忠诚为 `40+rand%40`；保留 OldBelong。

处斩保留装备字段，但将装备加入城市已发现队列，人物状态变为 Executed，不再被普通搜寻使用。流放改为在野，随机加入目标城队首，不改装备、兵力、忠诚或城市归属。
