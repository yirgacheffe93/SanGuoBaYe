## 当前主要技术风险

| 风险 | 应对 |
|---|---|
| main 规则主要位于 WASM，示例脚本易误导 | 只信可观察状态和 golden；逐命令冻结验收 |
| 内容规模远大于 R0 | 自动导入、Schema、原索引映射，不手工抄写大表 |
| 完整战略与战术范围大 | M1/M2/M3 垂直切片，每阶段保留可运行构建 |
| AI 与战斗等价成本 | 先实际行为再逐步对齐，不宣称初版规则式 AI 已等价 |
| 存档漂移 | 完整快照、RNG 当前状态、规范化哈希和连续性测试 |

每个里程碑以真实可玩流程和 main 对照结果验收，不以文件数量或静态界面代替完成度。
