# 22 · 搜寻可观测性与回归

> 状态：已完成。搜寻结果不再只表现为“无收获”，候选缺失和伯乐不匹配可以解释，现有 RNG 与 golden 未改变。

## 1. 当前搜寻能力

- 无收获。
- 金钱和粮食。
- 在野人物加入或拒绝。
- 道具发现并写入 `Discovered`。
- 防重复发现和存读档恢复。

## 2. 只读诊断

`MainSearchRules.Describe` 和 `MainGameSession.GetSearchDiagnostics` 提供：

- 本城在野人物数量。
- 本城未发现道具数量。
- 当前人物的伯乐条件是否匹配。
- “没有可招揽人物”“没有未发现道具”“伯乐条件不符合”等明确原因。

诊断只读取 World/Content，不推进 RNG，不修改人物、道具或队列。选择搜寻命令时，右侧会显示候选信息；执行后，月度报告使用对应的失败原因。

## 3. 典型场景

- 平原：吴懿、丁奉可作为在野候选人，存在加入或拒绝两种结果。
- 北平：公孙瓒可发现太玄兵符；发现后该项不再成为候选。
- 伯乐不匹配：只说明原因，不写发现位、不补抽候选。
- 无候选：不消耗候选选择 RNG，报告明确缺少人物或道具。
